Today is a synthesis day. You will see how all the tools from this course form a single coherent pipeline - and learn a decision framework for choosing the right tool at each stage.

The Six-Stage Pipeline

Every 3D web project moves through these stages. AI tools compress each one from hours to minutes.

1
Generate

Days 3, 8 - Meshy.ai or Tripo3D. Turn a text prompt or reference image into a 3D mesh in 2-5 minutes. This replaces hours of manual modeling.

2
Refine

Day 19 - Blender. Apply Decimate to reach web-friendly polygon counts (2,000-10,000 faces). Fix UV maps. Apply transforms. Pack textures.

3
Texture

Day 9 - AI texture tools like Leonardo.ai or Stable Diffusion. Generate tileable PBR textures from text descriptions. Apply in Blender's material editor.

4
Animate

Day 10 - Mixamo. Upload your mesh, auto-rig in 30 seconds, pick from 2,000+ motion-capture animations. Download FBX with Skin, re-export as animated GLB.

5
Render on the Web

Days 4-5, 11-12, 15 - Three.js or React Three Fiber. Load the optimized GLB, apply lighting, add interactivity. Apply performance patterns from Day 18.

6
Deploy

GitHub Pages for static sites (push, enable Pages, done). Vercel for React/Vite apps (connect repo, auto-deploy). Run gltf-transform before deploying.

Case Study: 3D Portfolio Website

Here is the full pipeline for building an animated developer character in a portfolio hero section:

Total time with AI tools: ~2 hours
Step 1: Meshy prompt "cartoon developer in hoodie, T-pose, game-ready" (15 min)
Step 2: Blender - Decimate to 5k faces, apply transforms, export GLB (20 min)
Step 3: Mixamo - auto-rig, pick Wave + Idle animations, re-export (10 min)
Step 4: gltf-transform optimize to under 3 MB (5 min)
Step 5: R3F - useGLTF + useAnimations, particle background (45 min)
Step 6: Vercel deploy from GitHub (5 min)
