Day 15: Browser 3D Games with Three.js

Build a complete browser game from scratch using Three.js — game loop, keyboard input, AABB collision, and a 30-second "collect the cubes" challenge.

The key concept: Every update must be multiplied by delta — the time in seconds since the last frame. This makes your game run at the same speed on a 30Hz tablet and a 144Hz gaming monitor.

The Game Loop

1
Create the clock 
const clock = new THREE.Clock();

THREE.Clock measures real wall-clock time between calls, not frame count.

2
Measure delta each frame 
function animate() {
  requestAnimationFrame(animate);
  const delta = clock.getDelta(); // seconds since last call
  update(delta);
  renderer.render(scene, camera);
}

getDelta() returns roughly 0.016 at 60 FPS and 0.033 at 30 FPS.

3
Scale all movement by delta 
// Without delta: speed depends on frame rate
player.position.x += 0.05;  // BAD

// With delta: always 5 units per second
player.position.x += 5 * delta;  // GOOD
4
Poll keyboard input 
const keys = {};
window.addEventListener('keydown', e => { keys[e.code] = true; });
window.addEventListener('keyup',   e => { keys[e.code] = false; });

// In update():
if (keys['KeyW']) player.position.z -= speed * delta;
if (keys['KeyS']) player.position.z += speed * delta;
5
AABB collision check 
function aabbOverlap(posA, posB, sizeA, sizeB) {
  const half = (sizeA + sizeB) / 2;
  return (
    Math.abs(posA.x - posB.x) < half &&
    Math.abs(posA.y - posB.y) < half &&
    Math.abs(posA.z - posB.z) < half
  );
}

Returns true when two axis-aligned boxes overlap on all three axes.

6
Game state management 
const state = {
  phase:    'playing', // 'playing' | 'gameover'
  score:    0,
  timeLeft: 30,
};

function update(delta) {
  if (state.phase !== 'playing') return;
  state.timeLeft -= delta;
  if (state.timeLeft <= 0) {
    state.phase = 'gameover';
  }
  // ... rest of update
}
When to add a physics engine

Manual AABB works fine for simple rectangular objects. Once you need gravity, rolling, stacking, or non-box shapes, use @dimforge/rapier3d-compat. Rapier runs as WebAssembly — fast enough for hundreds of rigid bodies in the browser. 

import RAPIER from '@dimforge/rapier3d-compat';
await RAPIER.init(); // loads WASM binary
const world = new RAPIER.World({ x: 0, y: -9.81, z: 0 });
// In the loop: world.step(); then copy positions back to meshes.
Fast-moving objects can skip through geometry in a single frame if they move farther than the object size between updates. Clamp high-speed objects or use Rapier's continuous collision detection (CCD) for bullets and projectiles.
