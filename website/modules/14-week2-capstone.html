Day 14: Week 2 Capstone — 3D Product Configurator

Build a complete, deployable 3D product configurator with React Three Fiber — GLB model loading, real-time color switching, and professional lighting.

What you will build: A React app where users can view a 3D product from any angle and switch its color in real time. The same architecture powers real-world configurators at sneaker brands, furniture stores, and car manufacturers.

Build Steps

1
Scaffold the project 
npm create vite@latest product-configurator -- --template react
cd product-configurator
npm install three @react-three/fiber @react-three/drei

Place your GLB file at public/models/product.glb.

2
Add the Canvas and Environment 
import { Canvas } from '@react-three/fiber'
import { Environment, OrbitControls } from '@react-three/drei'

<Canvas shadows camera={{ position: [0, 1, 4], fov: 45 }}>
  <Environment preset="studio" background={false} />
  <OrbitControls enableDamping dampingFactor={0.05} />
</Canvas>
3
Load the model with useGLTF 
import { useGLTF } from '@react-three/drei'
import { useEffect } from 'react'

function ProductModel({ color }) {
  const { scene } = useGLTF('/models/product.glb')

  useEffect(() => {
    scene.traverse((child) => {
      if (child.isMesh) {
        if (!child.userData.originalMaterial) {
          child.material = child.material.clone()
          child.userData.originalMaterial = true
        }
        child.material.color.set(color)
      }
    })
  }, [scene, color])

  return <primitive object={scene} scale={1.5} />
}
4
Wrap in Suspense for loading state 
import { Suspense } from 'react'

function LoadingCube() {
  return (
    <mesh>
      <boxGeometry args={[1, 1, 1]} />
      <meshStandardMaterial color="#888" wireframe />
    </mesh>
  )
}

// Inside Canvas:
<Suspense fallback={<LoadingCube />}>
  <ProductModel color={selectedColor} />
</Suspense>
5
Add a color picker UI 
const [selectedColor, setSelectedColor] = useState('#1a1a1a')

const COLORS = [
  { label: 'Black',  hex: '#1a1a1a' },
  { label: 'White',  hex: '#f5f5f5' },
  { label: 'Blue',   hex: '#1a6eb5' },
  { label: 'Red',    hex: '#c0392b' },
]

{COLORS.map(c => (
  <button
    key={c.hex}
    style={{ '--swatch-color': c.hex }}
    className={`swatch${selectedColor === c.hex ? ' active' : ''}`}
    onClick={() => setSelectedColor(c.hex)}
    title={c.label}
  />
))}
6
Deploy to Vercel 
npm run build
npx vercel --prod

Vercel auto-detects a Vite project. The public/ folder (including your GLB) is served as static assets.

Why clone the material? useGLTF caches loaded models globally. If you modify a cached material directly, every instance of that model in your app changes color. Cloning with material.clone() gives each component its own copy to modify safely.
