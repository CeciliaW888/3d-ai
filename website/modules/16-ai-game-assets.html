The 5-Stage AI Asset Pipeline

Every game-ready asset travels through five stages. Understanding each stage lets you catch quality problems early — before they compound.

1
Generate

Use Meshy.ai or Tripo3D with a detailed text prompt. Include style keywords like "low-poly", "game asset", and "clean topology" to bias the result toward web-ready geometry.

2
Cleanup

Open the GLB in Blender. Apply the Decimate modifier to hit your polygon budget. Fix inverted normals using Viewport Overlay > Face Orientation — red faces need flipping.

3
Optimize

Export as Draco-compressed GLB: npx @gltf-transform/cli optimize in.glb out.glb --compress draco. Target textures of 512×512 for mobile, 1024×1024 for desktop.

4
Rig

Upload to Mixamo's Auto-Rigger. Mark the chin, wrists, and elbows in the wizard. Mixamo places a full skeleton in seconds. Download as FBX with skin.

5
Animate

Browse Mixamo's 2,500+ motion clips. Download the animation as FBX "without skin". Import both rigged mesh and animation into Blender, then export as one GLB with embedded animations.

Polygon Budgets for Web Games

📐
Mobile web: 2,000–5,000 triangles per object, 512×512 textures.
Desktop web: 10,000–50,000 triangles per object, up to 2048×2048.
Multiply your per-object budget by simultaneous object count — 50 enemies at 5k each = 250k triangles just for enemies.

Level of Detail (LOD)

Three.js LOD swaps meshes automatically based on camera distance. Create three export versions (high, mid, low) from the same Blender file using the Decimate modifier at ratios 1.0, 0.3, and 0.08.

const lod = new THREE.LOD();
lod.addLevel(highPolyMesh,  0);   // full detail close up
lod.addLevel(midPolyMesh,  10);   // medium at 10 units
lod.addLevel(lowPolyMesh,  50);   // low-poly at distance

scene.add(lod);

// In animate():
lod.update(camera);   // auto-switches based on distance
