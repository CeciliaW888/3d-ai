Week 1 Capstone: AI 3D Hero Section

You have all the building blocks. Today you ship something real: a landing page hero with an AI-generated 3D model embedded via Three.js. This is the kind of section that makes visitors stop scrolling.

Project goal: Generate a 3D object with Meshy.ai, download the GLB, and embed it in a complete HTML file with a floating animation and responsive CSS.

The 5-Step Build

1
Generate on Meshy.ai

Use a short, concrete prompt: "ceramic coffee mug, product photography style" or "crystal gem, blue tones". Simple shapes with clear surfaces generate the cleanest results. Download the GLB.

2
Set up the scene

You need a WebGLRenderer, a PerspectiveCamera, a Scene, and two lights. Two lights is usually enough: an AmbientLight (soft fill) and a DirectionalLight (key light for shading).

3
Load the GLB with GLTFLoader

After loading, compute a bounding box, then center and scale the model to fit in a 2-unit cube. This is essential because AI-generated models have unpredictable origin points and sizes.

4
Add animation

Two lines of code in the render loop create a polished floating effect:

model.rotation.y += 0.003;
model.position.y = Math.sin(t * 0.8) * 0.08;

The Y rotation gives it a slow spin. The sine wave makes it float up and down.

5
Responsive canvas + loading state

Size the canvas with CSS (width: min(480px, 90vw)) and listen for window.resize to update the renderer. Show a CSS spinner over the canvas until the GLB loads.

Performance Rules

Cap the pixel ratio: Always call renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)). On Retina screens, rendering at 3x or 4x gives no visible benefit and can triple your GPU load.
Target file size: Keep your GLB under 3 MB for a good first-load experience. Run the file through gltf.report to check the triangle count and file size.

Quick Knowledge Check

After loading a GLB with GLTFLoader, the model appears huge and off-center. What is the correct way to fix this?

Mobile fallback tip: Add @media (pointer: coarse) CSS to reduce the canvas height on touch devices, saving battery and reducing draw calls on slower mobile GPUs.
