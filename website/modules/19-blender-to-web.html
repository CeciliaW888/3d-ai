Day 19 - Blender to Web: Export Pipeline

What you'll learn today: How to export a 3D model from Blender as a production-ready GLB file, optimize it with gltf-transform, and load it in Three.js or React Three Fiber.

The Blender Export Flow

Blender is the bridge between AI-generated models and your web scene. The export pipeline has three phases: prepare in Blender, optimize with gltf-transform, and load in the browser.

1
Prepare in Blender

Apply all modifiers (right-click each one). Apply transforms with Ctrl+A > All Transforms. Pack textures with File > External Data > Pack Resources.

2
Export as GLB

File > Export > glTF 2.0. Choose GLB format. Enable "Apply Transformations" and "Draco Mesh Compression" under Data > Mesh. This gives you a single compressed binary file.

3
Optimize with gltf-transform

Run the CLI to further reduce file size. Inspect first, then optimize. Target under 3 MB for most web models.

gltf-transform Commands

Install once: npm install -g @gltf-transform/cli 
# Inspect what's inside your file
npx gltf-transform inspect input.glb

# Compress with Draco (5-10x size reduction)
npx gltf-transform optimize input.glb output.glb --draco

# Resize embedded textures to 1024px
npx gltf-transform resize --width 1024 --height 1024 input.glb output.glb

Loading in Three.js

Draco requires a decoder: If you compressed with Draco, you must use DRACOLoader alongside GLTFLoader - otherwise the model will fail to load silently. 
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';
import { DRACOLoader } from 'three/examples/jsm/loaders/DRACOLoader.js';

const dracoLoader = new DRACOLoader();
dracoLoader.setDecoderPath('https://www.gstatic.com/draco/versioned/decoders/1.5.6/');

const loader = new GLTFLoader();
loader.setDRACOLoader(dracoLoader);

loader.load('/models/character.glb', (gltf) => {
  scene.add(gltf.scene);
});
