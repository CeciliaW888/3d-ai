Day 3: Text-to-3D AI — Meshy & Tripo3D

The shift: Until 2023, creating a 3D model took hours in Blender. Today you type a sentence and get a textured, web-ready GLB in under 2 minutes. AI 3D generation is the skill multiplier for everything else in this course.

How AI 3D Generation Works

Modern text-to-3D tools use a combination of techniques under the hood:

  • Diffusion models — generate multi-view images of the object from the text prompt
  • 3D reconstruction — converts those multi-view images into a 3D mesh with estimated depth
  • Texture projection — maps the generated images back onto the mesh as UV-unwrapped textures
Results vary significantly based on how specific your prompt is. "A medieval sword" gives a generic result. "A weathered iron longsword with a golden crossguard and leather grip wrap, game-ready low-poly" gives a much better one.

Meshy.ai Workflow

1
Go to meshy.ai, create a free account. You get free credits each day.
2
Choose Text to 3D. Enter your prompt. Add a negative prompt for things to avoid (e.g., "blurry, low quality").
3
Meshy generates 4 previews. Pick the best one and refine it (runs the texture generation pass).
4
Download as GLB. Your file includes the mesh + PBR textures (albedo, normal, roughness) baked in.

Loading Your GLB in Three.js

import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load('./my-model.glb', (gltf) => {
  scene.add(gltf.scene);
  // Center the model
  const box = new THREE.Box3().setFromObject(gltf.scene);
  const center = box.getCenter(new THREE.Vector3());
  gltf.scene.position.sub(center);
});
AI 3D limitations: Generated meshes often have poor topology (irregular triangle distribution) and may need cleanup in Blender if you want to rig them for animation. For static display on the web, they work great as-is.

How do tools like Meshy.ai generate a 3D model from a text prompt?

  • Photogrammetry from stored real-world photos
  • Neural Radiance Field (NeRF) training
  • Diffusion-generated multi-view images reconstructed into a mesh
  • Procedural voxel modeling

Why is GLB the best format to download from AI 3D tools for web projects?

  • It bundles geometry and PBR textures in one binary file, ready for Three.js
  • It is the lightest format with no texture data
  • It stores animation rigs better than any other format
  • It can be opened directly as an image
