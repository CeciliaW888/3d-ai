Image-to-3D AI Tools

Text-to-3D is powerful, but sometimes you have a real product photo and need a 3D version of it. Three fundamentally different technologies tackle this problem - and each has a different set of trade-offs for web use.

Three Approaches

Photogrammetry - Takes 30-200 photos of a real object from all angles and reconstructs geometry by matching features across images. Tools: Polycam (mobile), Metashape, RealityCapture. Produces the most accurate results but requires many photos and generates very dense meshes.
NeRF (Neural Radiance Field) - You walk around an object with your phone recording a video. A neural network learns to predict color and opacity at any point in 3D space from that footage. Luma AI is the most accessible NeRF capture tool. Results are photorealistic but the mesh conversion step is imperfect.
Diffusion-based (AI generative) - You supply one or a few photos. The AI infers the unseen sides using a diffusion model trained on millions of 3D objects. Tools: Meshy.ai, CSM, Stable Zero123. Fast (under 2 minutes), outputs a clean GLB, but the back of the model is an educated guess.

The Cleanup Workflow

Even AI-generated GLBs sometimes need cleanup before they're production-ready. Here's the fast path:

1
Check at gltf.report - triangle count should be under 100k, file size under 3 MB for a web hero.
2
If too dense, open in Blender, select the mesh, add a Decimate modifier at 0.2-0.5 ratio, and re-export as GLB.
3
Check for inverted normals (dark patches on the model) in Blender's Edit Mode - select all and Mesh > Normals > Recalculate Outside.
4
Apply Draco compression with npx gltf-pipeline -i model.glb -o model-compressed.glb -d for 60-80% file size reduction.

An architect needs a 3D model of a physical building model that must be dimensionally accurate. Which technique is most appropriate?

Diffusion models hallucinate the back: If your product has unique, non-symmetric back details (a label, a port, an embossed logo), a diffusion model will invent something plausible but wrong. In those cases use photogrammetry or photograph all angles and do a multi-view input.
