Day 10: AI Animation — Mixamo & Beyond

Still 3D is impressive. Animated 3D is alive. Today you learn how skeletal animation works, how Mixamo turns any humanoid mesh into a walking, running character in minutes, and how Three.js's AnimationMixer plays those animations in the browser.

Key insight: The visible mesh never moves on its own. It is skinned to a hidden skeleton (armature) made of bones. Animate the bones — the mesh follows.

How Skeletal Animation Works

An armature is a hierarchy of bones. Each bone has a parent (the spine is parent to the ribs) so rotating one joint automatically carries all its children — exactly like a real body. Skinning binds each mesh vertex to nearby bones with influence weights, so a knee vertex smoothly deforms as both the thigh and shin bones rotate. Keyframes record bone transforms at specific times; the engine interpolates the frames between them to produce fluid motion.

The Mixamo Workflow

1
Upload your mesh — FBX or OBJ, humanoid in T-pose. Meshes from Meshy.ai or Tripo3D work great.
2
Auto-rig — Place five body markers (head, chin, wrists, groin, knees). Mixamo AI generates a full ~65-bone rig in seconds.
3
Pick an animation — Search thousands of motion-captured clips. Preview them live on your character. Adjust Overdrive and Arm Space sliders.
4
Download GLB — Choose "FBX for Unity" or GLB. Check "Without Skin" if you only want the animation data.

AnimationMixer in Three.js

Three.js uses three classes to drive animation. An AnimationClip is a named set of keyframe tracks (one per bone property). An AnimationMixer is the playback engine — one per character. An AnimationAction is the handle you call .play() on. Call mixer.update(delta) every frame to advance time. 

import * as THREE from 'three';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

let mixer;
let idleAction;
let walkAction;
const clock = new THREE.Clock();

const loader = new GLTFLoader();
loader.load('/models/character.glb', (gltf) => {
  const model = gltf.scene;
  scene.add(model);

  mixer = new THREE.AnimationMixer(model);

  const idleClip = THREE.AnimationClip.findByName(gltf.animations, 'Idle');
  const walkClip = THREE.AnimationClip.findByName(gltf.animations, 'Walking');

  idleAction = mixer.clipAction(idleClip);
  walkAction = mixer.clipAction(walkClip);
  idleAction.play();
});

// Smooth transition on keypress
document.addEventListener('keydown', (e) => {
  if (e.key === 'w' && mixer) {
    idleAction.crossFadeTo(walkAction, 0.5, false);
    walkAction.play();
  }
});

function animate() {
  requestAnimationFrame(animate);
  const delta = clock.getDelta(); // seconds since last frame
  if (mixer) mixer.update(delta);
  renderer.render(scene, camera);
}
animate();
Common mistake: Passing clock.getElapsedTime() to mixer.update() instead of clock.getDelta() makes animations run faster and faster until they become a blur. Always use getDelta().

AI Motion Tools Beyond Mixamo

Cascadeur uses physics-based AI for any character shape — not just humanoids — and auto-generates secondary motion like hair and clothing sway. Move.ai captures motion from ordinary phone video using AI pose estimation, no motion-capture suit needed. Both export FBX/BVH that AnimationMixer can play.

Tip: Download multiple animations from Mixamo as separate GLBs, then merge them into one file in Blender by importing each and using "Push Down" in the NLA editor. Three.js will see all clips in gltf.animations.
