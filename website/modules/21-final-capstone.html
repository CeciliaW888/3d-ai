Choose Your Project

Option A - 3D Portfolio Hero

A 3D product viewer with color-change controls. The user clicks color swatches and the material updates live. Deploy to GitHub Pages.

Option C - Mini Browser Game
A 3D collectible game. Move a sphere with arrow keys and collect floating cubes to earn points. Score displayed in HTML.

Option D - Interactive Art Piece
A fullscreen GLSL shader scene that creates flowing color waves responding to your mouse position.
Stack: Three.js + GLSL vertex and fragment shaders
Best for: Learners who love visual art and want to go deep on shaders.

Deploy in 5 Minutes

1
GitHub Pages (vanilla Three.js)

Push to a GitHub repo. Go to Settings > Pages > Source: main branch. Your site is live at username.github.io/repo-name within 2 minutes.

2
Vercel (React + Vite)

Connect your GitHub repo at vercel.com. Vercel auto-detects Vite and runs npm run build. You get a live URL and automatic deploys on every push.

Before deploying: Run npx gltf-transform optimize input.glb output.glb --draco on any 3D models. A 1-minute optimization step can cut load time in half for users on mobile.
