Day 2: The 3D Software Landscape

The right tool for the job: You don't need to master every 3D tool — you need to know which one to reach for. This map will guide every decision in the course.

The Core Tools

1
Blender — free, open-source 3D modeling/animation suite. Use it for: precise modeling, UV unwrapping, rigging, and exporting clean GLB files. Steep learning curve, but unmatched power.
2
Three.js — JavaScript WebGL library. Use it for: any 3D you write code for — games, interactive scenes, data viz. No visual editor, full programmatic control.
3
React Three Fiber (R3F) — Three.js with JSX. Use it for: 3D inside React apps. Brings component reusability, hooks, and state management to 3D.
4
Spline — no-code browser-based 3D editor. Use it for: hero sections and marketing 3D without writing any Three.js. Export as embeddable web component.
5
Meshy.ai / Tripo3D — AI text-to-3D generators. Use them for: rapid asset creation from text or image prompts. Output: GLB/OBJ files with textures ready for the web.

The Universal Format: GLB / GLTF

GLTF (GL Transmission Format) is the "JPEG of 3D" — a compact, web-optimized 3D file format created by the Khronos Group. GLB is the binary single-file version that bundles geometry, textures, and animations into one file.

Why GLB? OBJ requires separate material files. FBX is proprietary (Autodesk). GLB is open-standard, smaller, loads faster, and natively supported by Three.js, R3F, Spline, and model-viewer.

Which file format is considered the standard for 3D on the web?

  • GLB (binary GLTF)
  • FBX (Autodesk)
  • OBJ (Wavefront)
  • SVG

Which tool lets you create an interactive 3D web scene without writing any code?

  • Blender
  • Three.js
