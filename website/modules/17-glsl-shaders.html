Day 17 — GLSL Shaders: Visual Magic Shaders run on the GPU, not the CPU. They are the reason modern 3D looks so good. Today you write your first vertex and fragment shader pair.

Two Programs, One Frame

Every WebGL draw call runs two small programs on the GPU:

📍
Vertex shader — runs once per vertex. Outputs gl_Position (clip-space coordinate). You can displace geometry here (waves, ripples, wind).

Fragment shader — runs once per pixel. Outputs gl_FragColor (RGBA color). You control every pixel's appearance here.

GLSL Syntax at a Glance

// Core types
float f = 1.0;              // always use decimal point
vec2  uv    = vec2(0.5, 0.5);
vec3  color = vec3(1.0, 0.0, 0.0);   // red
vec4  rgba  = vec4(color, 1.0);       // add alpha channel

// Swizzling — access components by name
vec2 xy = rgba.xy;    // first two components
vec3 rgb = rgba.rgb;  // same as vec3(rgba.r, rgba.g, rgba.b)

// Built-in functions
float t = sin(u_time);           // oscillates -1 to 1
float f = fract(x * 5.0);       // fractional part — repeating patterns
vec3  c = mix(colorA, colorB, t); // linear interpolation
float v = clamp(x, 0.0, 1.0);   // constrain to [0, 1]
🔗
Uniforms are JS values sent to both shaders — same across all vertices/pixels (time, resolution, mouse position).
Varyings are computed in the vertex shader and interpolated to the fragment shader — the UV coordinate is a classic example.

Complete Animated Wave ShaderMaterial

import * as THREE from 'three';

const material = new THREE.ShaderMaterial({
  uniforms: {
    u_time: { value: 0.0 }
  },
  vertexShader: /* glsl */ `
    uniform float u_time;
    varying vec2  v_uv;

    void main() {
      v_uv = uv;
      vec3 pos = position;

      // Displace Z to create wave
      pos.z += sin(pos.x * 3.0 + u_time)       * 0.15;
      pos.z += sin(pos.y * 2.0 + u_time * 0.7) * 0.15;

      gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
    }
  `,
  fragmentShader: /* glsl */ `
    uniform float u_time;
    varying vec2  v_uv;

    void main() {
      vec3 teal   = vec3(0.05, 0.58, 0.53);
      vec3 orange = vec3(0.90, 0.40, 0.10);

      float wave = sin(v_uv.x * 6.28 + u_time) * 0.5 + 0.5;
      wave = mix(wave,
                 sin(v_uv.y * 6.28 - u_time * 0.6) * 0.5 + 0.5,
                 0.5);

      gl_FragColor = vec4(mix(teal, orange, wave), 1.0);
    }
  `
});

// Geometry needs segments for the wave displacement to look smooth
const geometry = new THREE.PlaneGeometry(4, 4, 32, 32);
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// Update time every frame
const clock = new THREE.Clock();
function animate() {
  requestAnimationFrame(animate);
  material.uniforms.u_time.value = clock.getElapsedTime();
  renderer.render(scene, camera);
}
animate();

Same Shader in React Three Fiber

import { shaderMaterial } from '@react-three/drei';
import { extend, useFrame } from '@react-three/fiber';
import { useRef } from 'react';

const WaveMaterial = shaderMaterial(
  { u_time: 0 },
  // vertex
  `uniform float u_time; varying vec2 v_uv;
   void main() {
     v_uv = uv;
     vec3 pos = position;
     pos.z += sin(pos.x * 3.0 + u_time) * 0.15;
     gl_Position = projectionMatrix * modelViewMatrix * vec4(pos, 1.0);
   }`,
  // fragment
  `uniform float u_time; varying vec2 v_uv;
   void main() {
     float wave = sin(v_uv.x * 6.28 + u_time) * 0.5 + 0.5;
     gl_FragColor = vec4(mix(vec3(0.05,0.58,0.53), vec3(0.9,0.4,0.1), wave), 1.0);
   }`
);
extend({ WaveMaterial });

function WavePlane() {
  const mat = useRef();
  useFrame(({ clock }) => { if (mat.current) mat.current.u_time = clock.getElapsedTime(); });
  return (
    <mesh>
      <planeGeometry args={[4, 4, 32, 32]} />
      <waveMaterial ref={mat} />
    </mesh>
  );
}
