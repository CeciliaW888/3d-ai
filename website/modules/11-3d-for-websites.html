Day 11: 3D for Websites — Scroll & Parallax

When a 3D scene responds to scroll, it stops being decoration and becomes navigation. Today you learn how to architect scroll-driven Three.js scenes, map scroll progress to 3D transforms, and create the kind of layered parallax depth used on award-winning websites.

Key insight: Scroll-driven 3D works by normalizing scroll position to a 0-to-1 number and lerp-ing a 3D property toward the target on every animation frame. Never set values directly in the scroll event — lerp inside requestAnimationFrame.

Canvas Positioning Strategies

How the canvas sits in the DOM determines what scroll behavior you can build. Choosing the wrong strategy creates scrolling glitches that are painful to debug.

1
Fixed canvas — position: fixed, full viewport, behind page content. Best for a single 3D scene that spans the whole page. Simplest setup.
2
Sticky canvas — Canvas inside a tall wrapper div with position: sticky; top: 0. Active only while its section is in view. Great for multi-chapter pages with distinct 3D moments.
3
Inline canvas — Normal block element in document flow. Use IntersectionObserver to pause rendering when off-screen. Most performance-friendly for pages with many 3D sections.

Mapping Scroll to 3D State

Normalize the scroll position to a 0-to-1 fraction. Use it to compute target values for camera position, rotation, or any other property. Then lerp each rendered value toward its target every frame for smooth motion. 

import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 100);
camera.position.set(0, 0, 5);

const renderer = new THREE.WebGLRenderer({ antialias: true, alpha: true });
renderer.setSize(innerWidth, innerHeight);
renderer.domElement.style.position = 'fixed';
renderer.domElement.style.top = '0';
renderer.domElement.style.left = '0';
renderer.domElement.style.zIndex = '-1';
document.body.appendChild(renderer.domElement);

document.body.style.height = '400vh'; // make page scrollable

const geo = new THREE.TorusKnotGeometry(1, 0.3, 128, 32);
const mat = new THREE.MeshStandardMaterial({ color: 0x6d5eff });
const mesh = new THREE.Mesh(geo, mat);
scene.add(mesh);
scene.add(new THREE.AmbientLight(0xffffff, 0.5));
scene.add(Object.assign(new THREE.PointLight(0xffffff, 2, 20), { position: { x: 5, y: 5, z: 5 } }));

let targetRotationY = 0;
let targetCameraZ = 5;
let currentRotationY = 0;
let currentCameraZ = 5;

window.addEventListener('scroll', () => {
  const scrollFraction = window.scrollY / (document.body.scrollHeight - window.innerHeight);
  targetRotationY = scrollFraction * Math.PI * 2; // full rotation by page end
  targetCameraZ = 5 - scrollFraction * 3;         // drift camera closer
});

function animate() {
  requestAnimationFrame(animate);
  // Lerp: smooth chase toward target values
  currentRotationY += (targetRotationY - currentRotationY) * 0.08;
  currentCameraZ   += (targetCameraZ   - currentCameraZ)   * 0.08;
  mesh.rotation.y = currentRotationY;
  camera.position.z = currentCameraZ;
  renderer.render(scene, camera);
}
animate();
GSAP ScrollTrigger shortcut: In React Three Fiber, import gsap and ScrollTrigger, register the plugin, and use scrub: 1 in the trigger config to get built-in lerping without writing the math yourself. Set rotationTarget.current inside onUpdate, then read it in useFrame.

Parallax Depth Effect

Place several objects at different Z depths and advance each at a different scroll rate. A background particle cloud might move 0.1 units per 100px of scroll while a foreground logo moves 0.5 units — the difference in speed reads as depth to the eye.

Real-World Inspiration

Apple's product pages rotate and disassemble hardware in sync with scroll. Awwwards-winning sites morph geometry or form words from particles as you descend. Stripe's homepage uses a subtle 3D gradient mesh that parallaxes on scroll and hover. What these share: the motion never fights the user — it amplifies the gesture they are already making.

Performance warning: A fixed-canvas scene renders on every animation frame even when the user is not scrolling and nothing is moving. Add an IntersectionObserver that pauses renderer.setAnimationLoop(null) when the canvas is off-screen, and call renderer.setAnimationLoop(animate) when it returns.

Why should you lerp 3D values inside requestAnimationFrame rather than setting them directly inside the scroll event handler?

  1. Lerping produces smooth per-frame interpolation toward the target
  2. Scroll events update values at the render framerate automatically
  3. setTimeout adds the necessary delay for smooth motion
  4. requestIdleCallback ties scroll updates to the render loop
