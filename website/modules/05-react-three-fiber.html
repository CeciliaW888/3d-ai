Day 5: React Three Fiber: 3D in React

The big idea: React Three Fiber lets you describe a Three.js scene as a JSX component tree. Every Three.js class becomes a lowercase JSX tag — <mesh>, <boxGeometry>, <meshStandardMaterial> — and the scene graph is just React's component tree.

Why R3F?

Vanilla Three.js is imperative: you call scene.add(mesh), renderer.render(), manage cleanup yourself. React Three Fiber is declarative: you describe what should exist, and R3F handles creating, updating, and destroying Three.js objects as your React state changes. This means you get React state, hooks, context, and the entire React ecosystem working alongside your 3D scene.

The Canvas and Scene Graph

1
Wrap in <Canvas>

The root component that creates the WebGL renderer, default camera, and animation loop automatically.

2
Add a <mesh>

JSX children of mesh auto-attach: <boxGeometry> becomes mesh.geometry, <meshStandardMaterial> becomes mesh.material.

3
Animate with useFrame

The R3F hook that runs your callback every frame — useFrame((state, delta) => { ... }). Use delta for framerate-independent animation.

4
Add drei helpers

<OrbitControls> for camera, <Environment preset="city"> for lighting, <Html> for overlays.

Complete R3F Scene

import { Suspense, useRef } from 'react';
import { Canvas, useFrame } from '@react-three/fiber';
import { OrbitControls, Environment, useGLTF, Html } from '@react-three/drei';

function Model({ url }) {
  const { scene } = useGLTF(url);
  return <primitive object={scene} />;
}

function SpinningCube() {
  const ref = useRef();
  useFrame((state, delta) => {
    ref.current.rotation.y += delta * 0.8;
  });
  return (
    <mesh ref={ref}>
      <boxGeometry args={[1, 1, 1]} />
      <meshStandardMaterial color="#0d9488" roughness={0.3} metalness={0.2} />
    </mesh>
  );
}

export default function App() {
  return (
    <div style={{ width: '100vw', height: '100vh' }}>
      <Canvas camera={{ position: [0, 1.5, 4], fov: 60 }}>
        <Environment preset="city" />
        <Suspense fallback={
          <Html center><p style={{color:'white'}}>Loading…</p></Html>
        }>
          <Model url="/model.glb" />
        </Suspense>
        <OrbitControls />
      </Canvas>
    </div>
  );
}

Core Hooks Reference

useFrame(callback) — runs every animation frame inside the R3F loop. The callback receives (state, delta). State includes state.clock.elapsedTime for time-based effects.

useThree() — access the underlying renderer, scene, and camera from any component inside Canvas. Returns { scene, camera, gl, size }.

useGLTF(url) from drei — loads a GLB/GLTF model with automatic caching. Returns { scene, nodes, materials, animations }. Must be inside a Suspense boundary since it throws a Promise while loading.

The args prop: R3F JSX elements map to Three.js constructors. Pass constructor arguments as an array via the args prop. <sphereGeometry args={[0.5, 32, 32]} /> is equivalent to new THREE.SphereGeometry(0.5, 32, 32).
