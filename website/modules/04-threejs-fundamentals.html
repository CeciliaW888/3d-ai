Day 4: Three.js Fundamentals

Core pattern: Every Three.js scene needs exactly three things — a Scene (the world), a Camera (your viewpoint), and a Renderer (what draws pixels on screen). Everything else is optional.

What is Three.js?

Three.js is a JavaScript library that wraps WebGL — the browser's raw GPU API — into a clean, readable API. Writing WebGL by hand requires hundreds of lines of shader code for even a simple triangle. Three.js compresses that to a dozen lines of readable JavaScript while giving you full GPU power.

Three.js is the foundation for React Three Fiber, most 3D web demos you've seen, and thousands of production websites. Understanding it makes every other 3D web tool make more sense.

Scene, Camera, Renderer

1
Create a Scene

The container for all 3D objects, lights, and cameras. const scene = new THREE.Scene()

2
Add a Camera

PerspectiveCamera mimics a real camera — new THREE.PerspectiveCamera(75, aspect, 0.1, 100). The 75 is field-of-view in degrees.

3
Create a Renderer

WebGLRenderer draws the scene to a canvas — renderer.setSize(width, height) then append its domElement to the page.

4
Add a Mesh

Mesh = Geometry + Material. new THREE.Mesh(geometry, material) — then scene.add(mesh).

5
Run the Animation Loop

requestAnimationFrame calls your render function ~60 times per second, creating smooth animation.

Complete Spinning Cube — Setup

Project setup: Run npm create vite@latest my-scene -- --template vanilla, then npm install three. Replace src/main.js with the code below. 
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

// 1. Scene
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a2e);

// 2. Camera
const camera = new THREE.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  100
);
camera.position.set(0, 1, 3);

// 3. Renderer
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(window.devicePixelRatio);
document.body.appendChild(renderer.domElement);

// Mesh = Geometry + Material
const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial({
  color: 0x0d9488,
  roughness: 0.4,
  metalness: 0.2,
});
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// Lighting (MeshStandardMaterial needs it)
scene.add(new THREE.AmbientLight(0xffffff, 0.5));
const dirLight = new THREE.DirectionalLight(0xffffff, 1.5);
dirLight.position.set(5, 8, 5);
scene.add(dirLight);

// Interactive controls
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;

// Resize handler
window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});

// Animation loop
function animate() {
  requestAnimationFrame(animate);
  cube.rotation.x += 0.005;
  cube.rotation.y += 0.01;
  controls.update();
  renderer.render(scene, camera);
}
animate();

Geometry and Materials

Built-in geometries include BoxGeometry, SphereGeometry, PlaneGeometry, and CylinderGeometry. Each takes dimension arguments — SphereGeometry(0.5, 32, 32) creates a sphere with radius 0.5 and 32 segments of horizontal and vertical resolution.

MeshBasicMaterial ignores all lights and shows its color flat — useful for debugging. MeshStandardMaterial is physically-based (PBR) and responds to lights — use it for realistic objects. It requires at least one light in the scene or it renders black.

Loading a GLB Model

import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load('/model.glb', (gltf) => {
  scene.add(gltf.scene);
}, undefined, (error) => {
  console.error('Load error:', error);
});
Lights matter: If your loaded model looks completely black, add a THREE.AmbientLight and a THREE.DirectionalLight to the scene. MeshStandardMaterial requires lighting.
