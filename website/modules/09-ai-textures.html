AI Texture Generation

A 3D mesh with no texture is a grey blob. Textures are what give surfaces their identity: the roughness of concrete, the sheen of polished metal, the grain of wood. Today you learn the PBR texture system and how to apply it in Three.js.

The PBR Texture Set

Modern 3D rendering uses Physically Based Rendering (PBR). Instead of one "color image", you use a set of maps - each encoding a different physical property:

Albedo (Color Map) - The base color with no lighting baked in. Keep it free of highlights and shadows - Three.js computes those at runtime.
Normal Map - Encodes surface micro-detail (scratches, bumps, grout lines) as pixel colors. Fakes geometry without adding triangles. The single biggest visual quality improvement with zero performance cost.
Roughness Map - White pixels = rough/matte (diffuse scatter). Black pixels = smooth/specular (mirror-like). Controls how glossy the surface is.
Metalness Map - White = metallic (gold, steel). Black = non-metal (plastic, wood). Together with roughness this defines how the surface interacts with light.
Ambient Occlusion (AO) Map - Darkens crevices and contact points to simulate how ambient light gets blocked. Makes 3D feel grounded and real.

Free PBR Textures: Polyhaven

polyhaven.com is a library of CC0 (public domain) PBR texture sets. Every asset is free for commercial use, no attribution required. Download at 1K resolution for web use - 2K if you need close-up detail. Each download is a zip with all the maps pre-separated and correctly labeled.

Applying PBR in Three.js

Use MeshStandardMaterial - the PBR-ready material. Use one TextureLoader instance and call .load() per map.

Color space matters: Set colorSpace = THREE.SRGBColorSpace on the albedo map ONLY. Normal, roughness, metalness, and AO maps encode data values - not color - so they must stay in linear space. Getting this wrong makes the model look washed out or too dark. 
import * as THREE from 'three';

const loader = new THREE.TextureLoader();

// Albedo: needs sRGB color space
const albedoMap = loader.load('./textures/brick_albedo_1k.jpg');
albedoMap.colorSpace = THREE.SRGBColorSpace;

// Data maps: stay in linear space (default)
const normalMap    = loader.load('./textures/brick_normal_1k.jpg');
const roughnessMap = loader.load('./textures/brick_roughness_1k.jpg');
const aoMap        = loader.load('./textures/brick_ao_1k.jpg');

// Set tiling on all maps
[albedoMap, normalMap, roughnessMap, aoMap].forEach(t => {
  t.wrapS = t.wrapT = THREE.RepeatWrapping;
  t.repeat.set(2, 2);
});

const material = new THREE.MeshStandardMaterial({
  map:             albedoMap,
  normalMap:       normalMap,
  normalScale:     new THREE.Vector2(1, 1),
  roughnessMap:    roughnessMap,
  roughness:       1.0,
  aoMap:           aoMap,
  aoMapIntensity:  1.0
});

const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(1, 64, 64),
  material
);
// AO map needs a second UV attribute
sphere.geometry.setAttribute('uv2', sphere.geometry.attributes.uv);
scene.add(sphere);

AI Texture Generation Tools

When a texture doesn't exist in any library, AI generation is the answer:

1
Stable Diffusion (tiling mode) - Use "seamless tileable texture" in your prompt. Tools like AUTOMATIC1111 or ComfyUI support tiling output. Then use a normal map generator (normalmap.online) to derive the remaining maps.
2
Materialize (free) - Feed it any diffuse image and it auto-derives normal, roughness, metalness, and AO maps using image processing. No AI cost, works offline.
3
Adobe Substance 3D Sampler - Photograph any material and AI converts it to a full PBR set. The professional option - produces best results but requires a subscription.

Quick Knowledge Check

You are loading a PBR texture set with albedo, normal, roughness, and AO maps. On which map(s) should you set colorSpace = THREE.SRGBColorSpace?

Which PBR map makes a flat polygon appear to have surface bumps, scratches, and micro-detail without adding any extra triangles?

Quick tip - tiling scale: The repeat.set(2, 2) call tiles the texture 2x in each direction. For large architectural surfaces (a wall, a floor) you might use repeat.set(8, 8) to avoid the texture looking stretched. For a small object like a gem, keep it at (1, 1).
