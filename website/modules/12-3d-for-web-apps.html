Day 12: 3D for Web Apps — Configurators & Viewers

3D moves from decoration to utility when users can interact with it. A product configurator lets customers build emotional ownership before purchasing. Today you learn how to wire React state to 3D materials so clicking a color swatch updates a photorealistic model in real time.

Key insight: A configurator is a state machine. Selected options live in useState. The 3D model reads that state on every render. No imperative DOM manipulation — React's reconciler handles the update.

The R3F Configurator Pattern

Three concepts work together to build a configurator in React Three Fiber.

1
useState for selection — A color hex string, a material preset key, or a part index. When the user clicks a swatch, setSelectedColor re-renders only the affected mesh.
2
meshStandardMaterial for PBR — Pass color, roughness, and metalness as props. Changing any prop triggers a minimal re-render — no manual Three.js calls needed.
3
Environment for reflections — Wrap the scene in <Environment preset="studio" /> from drei. Metallic and glossy materials pick up HDR reflections automatically — no extra lights. 
import { useState, Suspense } from 'react';
import { Canvas } from '@react-three/fiber';
import { OrbitControls, Environment, useGLTF } from '@react-three/drei';

const COLOR_OPTIONS = [
  { label: 'Midnight', value: '#1a1a2e' },
  { label: 'Ocean',    value: '#0077b6' },
  { label: 'Coral',    value: '#e76f51' },
  { label: 'Sage',     value: '#74c69d' },
];

function ProductModel({ color }) {
  const { scene } = useGLTF('/models/product.glb');

  scene.traverse((node) => {
    if (node.isMesh && node.name.includes('Body')) {
      node.material = node.material.clone(); // avoid mutating shared material
      node.material.color.set(color);
    }
  });

  return <primitive object={scene} />;
}

useGLTF.preload('/models/product.glb');

export default function Configurator() {
  const [selectedColor, setSelectedColor] = useState(COLOR_OPTIONS[0].value);

  return (
    <div style={{ display: 'flex', gap: '2rem' }}>
      <div style={{ width: '600px', height: '500px' }}>
        <Canvas camera={{ position: [0, 1, 4], fov: 45 }}>
          <Suspense fallback={null}>
            <ambientLight intensity={0.3} />
            <Environment preset="studio" />
            <ProductModel color={selectedColor} />
            <OrbitControls enablePan={false} minDistance={2} maxDistance={8} />
          </Suspense>
        </Canvas>
      </div>

      <div>
        {COLOR_OPTIONS.map((opt) => (
          <button
            key={opt.value}
            onClick={() => setSelectedColor(opt.value)}
            style={{ background: opt.value, borderRadius: '50%', width: 40, height: 40 }}
          />
        ))}
      </div>
    </div>
  );
}

Suspense and Loading States

GLB files can be several megabytes. Without a loading state the canvas is blank while the file downloads. Wrap your model component in React <Suspense> and add <Loader /> from drei outside the Canvas for a ready-made progress overlay. Call useGLTF.preload(url) at module scope so downloading starts before the component mounts.

Environment Maps for Realistic Reflections

An environment map is an HDR panoramic image wrapped around the scene. Every reflective or glossy surface in the scene samples this image for its reflections. Drei's <Environment> has presets including studio, city, sunset, dawn, night, warehouse, and forest. Switching presets dramatically changes the mood of your material.

Material cloning: If multiple meshes share the same material instance, calling material.color.set() on one changes all of them. Always call node.material.clone() before modifying a material in a loaded model.

What does adding <Environment preset="studio" /> provide to materials in a React Three Fiber scene?

  1. Albedo texture for every mesh
  2. An HDR panoramic image for reflections on glossy and metallic surfaces
  3. Shadow maps from studio lights
  4. Normal map data for surface detail

Why call useGLTF.preload('/models/product.glb') at module scope?

  1. It prevents material sharing between mesh instances
  2. It shows a Suspense fallback while the model loads
  3. It enables OrbitControls on the loaded model
  4. It starts downloading the file before the component mounts, reducing loading time
